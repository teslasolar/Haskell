TEMPLATE SYSTEM B[3][1][0]

Three template layers:

T.atom(p)    Atomic elements
IDX.tpl(p)   Index page template
IDX.mini(p)  Minified single-line
AUTO.nav()   Auto-generated nav

MINIFIED INDEX TEMPLATE

IDX.tpl({uid,title,content,coord,css,back})

Params:
  uid     Header ID
  title   Page title / H2
  content PRE content
  coord   [x,y,z] block
  css     Stylesheet path
  back    Back link href

Output: ~200 byte HTML

AUTO-LOADER

AUTO.scan()    Get all blocks
AUTO.nav(f)    Generate nav HTML
AUTO.init()    Init on DOMReady

Elements:
  #auto-nav  Nav container
  #auto-map  Block map display
