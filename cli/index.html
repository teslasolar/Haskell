CLI WRAPPER

KONOMI:HASKELL Command Line Interface

konomi run <file.hs>
  Execute Haskell source file

konomi eval "<expr>"
  Evaluate expression

konomi compile <file.hs> [--target ast|core|stg]
  Compile to target

konomi type "<expr>"
  Get type of expression

konomi repl
  Interactive REPL

konomi serve [--port 3000]
  Start API server

konomi block <x> <y> <z>
  Get block by coordinate

konomi template <name> [--params '{}']
  Render template

INSTALL

# npm
npm install -g konomi-haskell

# or run directly
npx konomi-haskell run main.hs
