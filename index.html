HASKELL INVARIANTS

R1: Every expression has a type
R2: Functions are curried (a -> b -> c = a -> (b -> c))
R3: Pure functions: same input = same output, always
R4: Lazy: nothing evaluated until needed
R5: IO is explicit in types
R6: Pattern match must be exhaustive (warn)
R7: Type inference: signatures optional but recommended
R8: No mutation: "variables" are bindings, not boxes
