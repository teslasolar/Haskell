MCP SERVER

Model Context Protocol Server
For AI agent integration

Tools:
  haskell_run
    Execute Haskell source code
    Input: { src: string }
    Output: { output: string }

  haskell_eval
    Evaluate Haskell expression
    Input: { expr: string }
    Output: { value: any, type: string }

  haskell_type
    Get type of expression
    Input: { expr: string }
    Output: { type: string }

  haskell_compile
    Compile to AST/Core/STG
    Input: { src: string, target: string }
    Output: { result: object }

  konomi_block
    Get block by 3D coordinate
    Input: { x: int, y: int, z: int }
    Output: { path, coord, content }

  konomi_template
    Render atomic template
    Input: { name: string, params: object }
    Output: { html: string }

USAGE

# Add to Claude config
{
  "mcpServers": {
    "konomi-haskell": {
      "command": "node",
      "args": ["mcp/server.js"]
    }
  }
}
