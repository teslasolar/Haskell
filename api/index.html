API SPECIFICATION

KONOMI:HASKELL Backend API v1.0
Base: /api

POST /api/run
  Execute Haskell source
  Body: { src: String, mode?: String }
  Resp: { output: String, exitCode: Int }

POST /api/compile
  Compile to target
  Body: { src: String, target: 'ast'|'core'|'stg'|'cmm'|'asm' }
  Resp: { result: Object|String }

POST /api/eval
  Evaluate expression
  Body: { expr: String }
  Resp: { value: Any, type: String }

POST /api/type
  Get type of expression
  Body: { expr: String }
  Resp: { type: String }

GET /api/block/:x/:y/:z
  Get block by coordinate
  Resp: { path, coord, content }

POST /api/template
  Render template
  Body: { name: String, params: Object }
  Resp: { html: String }
