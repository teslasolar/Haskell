RUNTIME ENVIRONMENT

Supported Runtimes

GHC      Glasgow Haskell Compiler
         Full compilation to native
         ghc Main.hs -o main

GHCI     GHC Interactive
         REPL and scripting
         ghci / runghc Main.hs

LOCAL    Browser-based
         Parse + limited eval
         No external dependencies

API      Remote execution
         POST /api/run {src}
         Full GHC backend

MCP      AI agent runtime
         haskell_run tool
         Sandboxed execution

EXECUTION MODES

HASKELL.config.mode = 'local'|'api'|'cli'|'mcp'

local  Browser parser + eval
       No side effects
       Immediate response

api    HTTP to backend
       Full GHC support
       Network latency

cli    Spawn ghc/ghci
       Local machine
       Full capabilities

mcp    MCP protocol
       AI agent context
       Tool-based access
